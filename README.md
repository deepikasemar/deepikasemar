## About

<div align="center">

```text
I turn raw data into clear insights and working machine learning models.
```

</div>

I am a data scientist and engineer pursuing a B.Tech in Computer Science at Sardar Beant Singh State University, Gurdaspur. I build data-driven solutions in Python, from cleaning messy datasets to training models and presenting results that people can act on.

**What I do**

- Analyse and prepare data with Pandas, NumPy and SciPy
- Build, evaluate and tune machine learning models with Scikit-learn
- Explain findings through Matplotlib and Seaborn visualisations
- Query and manage data with SQL, MySQL and PostgreSQL
- Write clean, reproducible code in Python, C and C++
- Build end-to-end projects: salary prediction with linear regression, weather forecasting, and database-driven applications

**How I work**

- Start with the question, then let the data guide the method
- Validate every model with proper evaluation, not just accuracy
- Keep code readable, documented and easy to reproduce

**Open To**

- Data Scientist, Data Analyst and Machine Learning roles
- Internships and collaborative projects
- Open source contributions
